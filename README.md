# Javascript calc

Простой _калькулятор_ на _**JavaScript**_, собранный с помощью **Webpack**.

## Возможности

1. Вводить число
2. Выполнять мат операции

- Вводить число
- Выполнять мат операции
- Получать результат

## Установка проекта инструкция

1. Склонируйте репозиторий

   ```bash -это язык
   git clone https://github.io/
   ```

2. Установите зависимости:

```bash
npm install
```

3. Зпаустите проект:

```bash
npm run start
```

## Примеры кода

> Функция для подсчета суммы:

```javascript
function sum(a, b) {
  return a + b;
}
```

> Функция для вывода результата:

```javascript
function output(data) {
  console.log(data);
}
```

> Элемент для вывода результата:

```html
<div>
  <span id="result">0</span>
</div>
```
